# المدرب الرقمي — Demo إداري

عرض تفاعلي مستقل لمنصة إدارة التدريب النظري للكليات التقنية بمنطقة الرياض. الواجهة عربية RTL بهوية ليلية خضراء وخط Tajawal (يُحمّل من Google Fonts)، وتستخدم بيانات وهمية متسقة فقط.

## التشغيل

لا توجد حزم أو خادم أو قاعدة بيانات مطلوبة. افتح `index.html` في متصفح حديث، أو شغّل خادمًا محليًا من مجلد المشروع:

```powershell
python -m http.server 8080
```

ثم افتح `http://localhost:8080`.

### الفتح من الهاتف على نفس شبكة Wi-Fi

على الكمبيوتر، افتح PowerShell من مجلد المشروع وشغّل:

```powershell
.\start-phone-demo.ps1
```

سيعرض لك عنوان Wi-Fi مثل `http://192.168.1.104:8766`؛ افتحه من متصفح الهاتف بعد توصيل الهاتف والكمبيوتر بالشبكة نفسها. اترك نافذة PowerShell مفتوحة أثناء الاستخدام، وأوقف الخادم بـ`Ctrl+C`. إذا منع جدار الحماية الاتصال، اسمح باتصال Python على الشبكة الخاصة فقط. لا تستخدم شبكة عامة ولا تفتح المنفذ على الإنترنت؛ هذه نسخة Demo بلا مصادقة.

## ما يتضمنه العرض

- لوحة مؤشرات وكروت KPI ورسوم توضيحية.
- منشآت وأقسام ومستخدمون وأدوار وصلاحيات.
- مقررات وشعب ومحتوى واعتماد تجريبي.
- حضور وتقدم، تقارير وتصدير CSV تجريبي.
- جودة، سجل تدقيق، وإعدادات جلسة محلية.
- تنقل، بحث، فلاتر، نوافذ إجراءات، ورسائل نجاح ضمن الواجهة.
- خريطة SVG تفاعلية بعرض الصفحة في مقدمة لوحة الإدارة، بحدود المملكة المستمدة من بيانات Natural Earth 1:10m ونقاط اتصال ومسارات متحركة؛ الخريطة توضيحية للـDemo وليست مرجعًا حدوديًا رسميًا. يليها مباشرة شريط العبارة «نتدرب لنتعلم، ونتعلم لنتميز، ونتميز لنحقق».
- القوائم الجانبية تتبدل حسب دور العرض (قيادة المنطقة، الإشراف، العميد، الجودة، رئيس القسم، المدرب، والمتدرب). هذا تخصيص واجهة فقط وليس فرض صلاحيات.
- للمتدرب مساحة شخصية تشمل الرئيسية، المقررات، الجدول، الواجبات والاختبارات، النتائج، الحضور، الملف الشخصي، وقاعة محاضرة تفاعلية مستوحاة من ملف المرجع. التقدم والتسليمات تجريبية داخل الذاكرة، ولا يوجد حساب أو حفظ دائم أو اتصال ذكاء اصطناعي.
- الشرح الصوتي في قاعة المتدرب يبدأ مباشرة عند ضغط المستخدم ويطلب العربية (`ar-SA`) مع تفضيل صوت عربي متاح على الجهاز. يظل التنفيذ معتمدًا على تحويل النص إلى كلام في المتصفح/الجهاز؛ هذه ليست ملفات صوت مضمّنة، لذا قد يختلف الصوت أو لا يتوفر على بعض الأجهزة.
- لمسؤول الجودة مساحة مراجعة مفصلة تشمل مراجعة المحتوى، النتائج المجمعة، الاستبيانات الأسبوعية، مقارنة الكليات والأقسام، ملاحظات الجودة، وسجل التدقيق. تدعم الملاحظات دورة تجريبية: رصد ← توصية ← إجراء تصحيحي ← متابعة ← إغلاق. كل السجلات وهمية ومؤقتة في الذاكرة؛ الدور رقابي ولا يحرر الدرجات أو الحضور أو المحتوى.
- القائمة الجانبية لها تمرير مستقل عند فتحها على الشاشات الصغيرة أو عند زيادة عناصر التنقل.

كل تعديل يتم في الواجهة أو جلسة المتصفح فقط ولا يُحفظ. لا توجد مصادقة أو API أو قاعدة بيانات أو صلاحيات خادمية.

## التحقق المنفذ

- فحص بنية الملفات: لا توجد شفرة تطبيق أو مدير حزم أو إعدادات بناء أصلية.
- نجح `node --check` لملفات JavaScript الأربعة.
- فُحص العرض في متصفح عبر خادم محلي: استجاب زر نقطة الأفلاج، وتبدلت مساحة المتدرب المستقلة وقوائمها، وانتقلت قاعة المحاضرة بين خطوات الدرس وسؤال المراجعة بصورة تفاعلية.
- فُحص تمرير القائمة الجانبية في عرض الهاتف؛ ظهرت روابط التقارير والجودة والإعدادات بعد التمرير داخلها.
- مساحة الجودة الجديدة ومسارها التفاعلي أضيفا في `assets/quality-workspace.js`؛ يلزم إكمال فحص المتصفح لصفحاتها قبل اعتبارها متحققة بصريًا.
- لا توجد اختبارات أو أوامر build/lint مرفقة لتشغيلها.
- تبديل الدور في الـDemo يغير العرض فقط ولا يطبق مصادقة أو صلاحيات فعلية.
