# Design Specification — Admin Demo

## الاتجاه البصري
واجهة حكومية مؤسسية راقية، فاتحة وأنيقة، عربية RTL، مناسبة للعرض الرسمي. لا تستخدم لوحة أرقام عامة أو صورة ثابتة بدل المنتج.

## الجودة
- RTL حقيقي في القوائم والجداول والنماذج والأسهم والـ breadcrumbs.
- شريط جانبي بمجموعات تنقل وحالة نشطة واضحة.
- شريط علوي للبحث والتنبيهات والمستخدم وسياق المنشأة.
- عناوين ووصف مختصر وأزرار إجراءات متسقة.
- بطاقات KPI بتسمية ووحدة وفترة.
- رسوم بمحاور وتسميات ومصدر/فترة.
- جداول فيها بحث وفلاتر وحالات وإجراءات واضحة.
- حالات فارغة وتحميل وخطأ ونجاح برسائل عربية.
- نماذج تحقق وتأكيد للإجراءات الحساسة.
- تجنب الزخرفة المفرطة وLorem ipsum.
- Responsive وإمكانية وصول وتباين جيد.
- شارة دائمة: «بيانات تجريبية — ليست بيانات تشغيل فعلية».

## الصفحات
1. لوحة المؤشرات: المنشآت والأقسام والمقررات والمتدربون والتنفيذ والحضور والتقدم وتغطية العجز.
2. المنشآت: بحث وفلاتر وتفاصيل وأقسام وحالة؛ إجراءات Demo.
3. الأقسام: حسب المنشأة، تفاصيل ورئيس القسم.
4. المستخدمون: بحث وفلاتر حسب الدور والمنشأة والحالة، تفاصيل وتفعيل/تعطيل تجريبي.
5. الصلاحيات: مصفوفة قراءة/إضافة/تعديل/حذف/اعتماد/تصدير.
6. المقررات والشعب: المقرر والقسم والمدرب والفصل والشعبة وعدد المتدربين.
7. المحتوى: ملفات ودروس وحالة مراجعة واعتماد وملاحظات.
8. الحضور والتقدم: حاضر/متأخر/غائب/معذور وفلاتر.
9. التقارير: فلاتر ومعاينة وتصدير CSV إن أمكن وتعريف المؤشر وفترته.
10. الجودة والتدقيق: ملاحظات وسجل أحداث تجريبي قابل للفلترة.
11. الإعدادات: إعدادات Demo مع توضيح أنها غير متصلة بخادم حقيقي.

## السلوك
كل زر ظاهر ينفذ إجراءً أو يكون معطلًا مع تفسير. البحث والفلاتر تغير النتائج. التعديلات التجريبية تنعكس في الواجهة ولا تدّعي حفظًا دائمًا دون backend.
