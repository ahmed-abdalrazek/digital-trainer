# تعليمات Codex

1. اقرأ PRD.md وPROJECT_CONTEXT.md وDESIGN_SPEC.md وCODEX_TASKS.md قبل التعديل.
2. افحص Git status والمستودع والوثائق قبل التغيير.
3. لا تحذف أو تستبدل ملفات قبل فهمها.
4. استخدم التقنية الحالية قدر الإمكان.
5. نفّذ تغييرات صغيرة قابلة للاختبار، واكتب/حدّث الاختبارات.
6. لا تخترع مفاتيح أو نتائج اختبار ولا تضع أسرارًا في الشفرة.
7. بيانات Demo يجب أن تكون وهمية مع تنبيه واضح.
8. العربية RTL افتراضيًا؛ التصميم حكومي مؤسسي راقٍ وفاتح وأنيق.
9. كل زر ظاهر يعمل أو يوضح أنه غير متاح.
10. إخفاء الأزرار ليس حماية: فرض الصلاحيات خادميًا عند تجهيز المنتج.
11. افصل صلاحيات المنطقة والمنشأة والقسم والشعبة.
12. لا تمنح الجودة تعديل السجلات الأكاديمية الأصلية تلقائيًا.
13. لا تعتبر فتح الدرس وقت تدريب مكتمل.
14. وثّق الفجوات والقيود والاختبارات الفعلية وحدّث README.
15. لا تعلن جاهزية الإنتاج دون اختبارات صلاحيات وأمن واستعادة.
