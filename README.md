# المدرب الرقمي — العرض التجريبي

النسخة الرئيسية موجودة في جذر المشروع، وتبدأ مباشرة من `index.html`. الواجهة عربية RTL ومبنية بـ HTML وCSS وJavaScript دون إطار عمل أو حزم تشغيل.

> **تنبيه:** سجلات الإدارة والمتدرب والحضور والمؤشرات تجريبية وتظل في ذاكرة الصفحة الحالية. توجد قاعة واحدة حقيقية مدمجة من Tutori: تولّد درسًا وصوتًا وسبورة عبر OpenAI API عند الطلب. لا يوجد تسجيل دخول أو قاعدة بيانات أو حفظ دائم، ورفع الملفات غير متاح.

## التشغيل

- افتح `index.html` في متصفح حديث.
- لتشغيل خادم محلي، استخدم `php -S 127.0.0.1:8000` أو `python -m http.server 8000` من جذر المشروع.
- لتجربة العرض من الهاتف على شبكة Wi-Fi نفسها، شغّل `start-phone-demo.ps1` من PowerShell.

### تشغيل المحاضرة الحية

شغّل خادم Tutori في نافذة PowerShell أولى. عند أول تشغيل أنشئ البيئة الافتراضية وثبّت المتطلبات:

```powershell
Set-Location .\tutori
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
$env:OPENAI_API_KEY="مفتاح OpenAI API"
.\.venv\Scripts\python.exe app.py
```

في نافذة ثانية شغّل بوابة العرض من جذر المشروع:

```powershell
Set-Location C:\laragon\www\digital-trainer
python -m http.server 8000 --bind 127.0.0.1
```

افتح `http://127.0.0.1:8000`، بدّل الدور إلى «المتدرب»، ثم اختر «قاعة المحاضرة». إذا كان Laragon يشغّل بوابة العرض بالفعل، لا تحتاج إلى تشغيل خادمها مرة ثانية. زر «ابدأ المحاضرة» يفتح Tutori على `http://127.0.0.1:7860` في نافذة مستقلة، مع سؤال المحاضرة جاهزًا وزر البدء ظاهرًا.

## الصفحات

لوحة المؤشرات، المنشآت والأقسام، المستخدمون والأدوار، المقررات وتفاصيلها، الشعب التدريبية، المحتوى ومراجعته، الحضور والتقدم، التقارير، الجودة والتدقيق، والإعدادات. المقررات منفصلة عن الشعب والمحتوى. إجراءات الإضافة والتعديل والاعتماد في العرض تجريبية ومحلية.

مستندات المتطلبات والتصميم والقيود والتدقيق موجودة في مجلد `docs/` في جذر المشروع.

المحاضرة الحية الوحيدة في العرض هي «كيف تنتقل البيانات عبر شبكة الحاسب؟» ضمن الشبكات 101. تحتاج خادم Tutori ومفتاح OpenAI API مع رصيد؛ كل طلب شرح أو صوت يُحتسب على حساب API. صفحات المقررات الأخرى والحضور والنتائج تظل بيانات عرض ولا تدّعي حفظ حضور أو درجات حقيقية.

النسخة الإدارية الأقدم محفوظة في `legacy-admin-demo.html` مع `app.js` و`styles.css`.
