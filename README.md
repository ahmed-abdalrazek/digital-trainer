# المدرب الرقمي — عرض إدارة تجريبي

واجهة عرض تفاعلية عربية RTL لإدارة التدريب في الكليات التقنية بمنطقة الرياض. نقطة الدخول الرئيسية تفتح النسخة الأحدث في `digital_trainer_codex_handoff/`، والمبنية بـ HTML وCSS وJavaScript دون إطار عمل أو حزم تشغيل.

> **تنبيه:** جميع السجلات والمستخدمين والمؤشرات بيانات تجريبية. لا يوجد خادم أو قاعدة بيانات أو مصادقة أو حفظ دائم. لا تستخدم بيانات حقيقية.

## التشغيل

**فتح مباشر:** افتح `index.html` في متصفح حديث؛ ينتقل تلقائيًا إلى أحدث نسخة داخل `digital_trainer_codex_handoff/`.

**من الهاتف على شبكة Wi-Fi نفسها:** شغّل `digital_trainer_codex_handoff/start-phone-demo.ps1` من PowerShell واتبع عنوان Wi-Fi الذي يطبعه.

**خادم محلي اختياري (PHP):** من مجلد المشروع شغّل `php -S 127.0.0.1:8000` ثم افتح `http://127.0.0.1:8000`.

**خادم محلي اختياري (Python):** شغّل `python -m http.server 8000` ثم افتح `http://127.0.0.1:8000`.

## صفحات العرض

لوحة المؤشرات، الكليات والمنشآت، الأقسام، المستخدمون، الأدوار والصلاحيات، المقررات والشعب، المحتوى والاعتماد، الحضور والتقدم، التقارير ومؤشرات تغطية العجز، الجودة وسجل التدقيق، والإعدادات.

البحث والفلاتر والنماذج وتبديل الحالة واعتماد المحتوى ومعاينة CSV وتصديره تعمل محليًا. أي تغيير يظل في ذاكرة الصفحة الحالية ويزول عند تحديثها. معاينة رفع الملفات محلية ولا تنقل الملف إلى خادم.

## الفحص

- `node --check app.js` — فحص صياغة JavaScript.
- لا يوجد `package.json` أو إطار اختبار أو بناء أو lint أو اختبارات آلية قائمة.
- مستودع Git موجود في جذر المشروع. يجب أن ينشر GitHub Pages مجلد المستودع الجذري؛ تقوم صفحة `index.html` بتحويل الزوار إلى النسخة الأحدث المضمّنة.
- تفاصيل التدقيق والتتبع والقيود في [`docs/PROJECT_AUDIT.md`](digital_trainer_codex_handoff/docs/PROJECT_AUDIT.md)، [`docs/REQUIREMENTS_TRACEABILITY.md`](digital_trainer_codex_handoff/docs/REQUIREMENTS_TRACEABILITY.md)، و[`docs/DEMO_LIMITATIONS.md`](digital_trainer_codex_handoff/docs/DEMO_LIMITATIONS.md).

## تجهيز المنتج الفعلي

راجع فجوات الأمان والصلاحيات والبيانات والاختبارات في وثائق التدقيق. يجب تصميم خدمة backend ومخطط بيانات وعزل النطاقات التنظيمية ومصادقة وصلاحيات خادمية وتدقيق دائم واختبارات عزل واستعادة قبل استخدام بيانات حقيقية. هذا العرض ليس جاهزًا للإنتاج.

> النسخة الإدارية السابقة محفوظة في `legacy-admin-demo.html`، وملفاتها `app.js` و`styles.css` باقية دون حذف. افتح الملف القديم يدويًا عند الحاجة للمقارنة؛ أما رابط المشروع الأساسي فيفتح النسخة الأحدث.
