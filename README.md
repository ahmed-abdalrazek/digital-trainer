# المدرب الرقمي — العرض التجريبي

النسخة الرئيسية موجودة في جذر المشروع، وتبدأ مباشرة من `index.html`. الواجهة عربية RTL ومبنية بـ HTML وCSS وJavaScript دون إطار عمل أو حزم تشغيل.

> **تنبيه:** جميع السجلات والمستخدمين والمؤشرات بيانات تجريبية. التعديلات تظل في ذاكرة الصفحة الحالية، ولا يوجد خادم أو قاعدة بيانات أو مصادقة أو حفظ دائم. رفع الملفات الفعلي غير متاح.

## التشغيل

- افتح `index.html` في متصفح حديث.
- لتشغيل خادم محلي، استخدم `php -S 127.0.0.1:8000` أو `python -m http.server 8000` من جذر المشروع.
- لتجربة العرض من الهاتف على شبكة Wi-Fi نفسها، شغّل `start-phone-demo.ps1` من PowerShell.

## الصفحات

لوحة المؤشرات، المنشآت والأقسام، المستخدمون والأدوار، المقررات وتفاصيلها، الشعب التدريبية، المحتوى ومراجعته، الحضور والتقدم، التقارير، الجودة والتدقيق، والإعدادات. المقررات منفصلة عن الشعب والمحتوى. إجراءات الإضافة والتعديل والاعتماد في العرض تجريبية ومحلية.

مستندات المتطلبات والتصميم والقيود والتدقيق موجودة في مجلد `docs/` في جذر المشروع.

النسخة الإدارية الأقدم محفوظة في `legacy-admin-demo.html` مع `app.js` و`styles.css`.
