## الحالة عند الاستلام

- المسار الأعلى `C:\laragon\www\digital-trainer` ليس مستودع Git.
- مجلد المشروع `digital_trainer_codex_handoff` ليس مستودع Git أيضًا؛ لذلك تعذر الحصول على `git status` أو فرع أو سجل commits.
- الحزمة احتوت على ست وثائق فقط في `docs/`، ولا تحتوي قبل هذا التنفيذ على تطبيق أو HTML أو JavaScript أو CSS أو `package.json` أو `composer.json` أو ملف بيئة أو إعدادات تشغيل/اختبار.
- لا يوجد تصدير Base44، ولا وثيقة تسليم فني، ولا مخطط قاعدة بيانات/ترحيلات، ولا CSV للكليات، ولا ملفات مرجعية أخرى. لم تُفترض قراءتها أو وجودها.

## التقنية وأوامر التشغيل

لا توجد تقنية قائمة يمكن الاستمرار عليها. اختير Demo ثابت (HTML/CSS/JavaScript بلا مكتبات) حتى يبقى قابلاً للفتح دون تثبيت أو مفاتيح أو خدمات خارجية. تعليمات التشغيل في `README.md`.

## المنفذ في هذا التسليم

- Demo إداري تفاعلي في `index.html` و`assets/`، عربي RTL ومتجاوب.
- بيانات عرض وهمية، وتنبيه دائم يوضح أنها ليست بيانات تشغيل فعلية.
- صفحات المؤشرات، المنشآت، الأقسام، المستخدمين، الصلاحيات، المقررات والشعب، المحتوى، الحضور والتقدم، التقارير، الجودة، والإعدادات.
- بحث/فلاتر داخل صفحات البيانات، تنقل، نوافذ إجراءات، تبديل حالة مستخدم في الواجهة، اعتماد/تعديل تجريبي، وتصدير CSV محلي.

## الاختبارات المنفذة فعليًا

- نجح تحليل JavaScript الساكن لـ `assets/app.js`.
- نجح تحقق سكوني من وجود جميع صفحات الـDemo الإحدى عشرة ووثائق README والتدقيق وتتبع المتطلبات والقيود.
- لا توجد اختبارات وحدات أو lint أو build أو إعدادات CI مرفقة لتشغيلها.
- لم يكتمل فحص متصفح بصري لأن سياسة البيئة حجبت فتح `file://` المحلي. لا يعني ذلك نجاح تجربة سطح المكتب أو الجوال؛ يجب تنفيذها قبل العرض الرسمي.

## فجوات ومخاطر P0

1. لا توجد مصادقة أو جلسات أو إدارة هوية أو فرض صلاحيات خادمي.
2. لا توجد قاعدة بيانات أو عزل Region/Facility/Department/Section أو API.
3. لا يوجد رفع أو فحص ملفات، اعتماد بشري محفوظ، أو تخزين دائم.
4. لا يوجد احتساب موثوق للحضور أو التقدم أو التغطية؛ جميع الأرقام تجريبية.
5. لا يوجد سجل تدقيق غير قابل للعبث أو نسخ احتياطي أو اختبار استعادة.
6. لا توجد اختبارات آلية أو فحوص أمن/خصوصية أو اختبارات قبول للأدوار الثمانية.

## خطة الاستكمال المقترحة

1. **الأساس:** اعتماد التقنية المستهدفة، إنشاء Git وCI، إدارة أسرار، بيئات منفصلة، وتحديد مالك المنتج للمسائل المفتوحة في PRD.
2. **البيانات والصلاحيات:** بناء نموذج Region/Facility/Department/UserRole/Section وربط كل استعلام بسياسة نطاق خادمية؛ اختبارات منع IDOR وتغيير معرّفات المنشأة والقسم والشعبة.
3. **التدريب:** مقررات وشعب وتسجيلات وجلسات وحضور وتقدم وإقرارات وخطط تقييم، مع ترحيلات وبيانات seed تجريبية فقط.
4. **المحتوى والحوكمة:** رفع آمن، فحص نوع/حجم الملف، تخزين خاص، مسار مراجعة، audit log append-only، وملاحظات جودة لا تعدل السجل الأكاديمي الأصلي.
5. **التقارير والجاهزية:** تعريف رسمي للمؤشرات، توليد XLSX/PDF بصلاحيات، مراقبة، نسخ مشفرة، اختبار استعادة، وتهديدات/فحص أمني قبل بيانات حقيقية.

## أسئلة تحتاج قرارًا

- تعريف زمن التدريب وإثبات الإكمال ومصدر مؤشر تغطية العجز.
- مصفوفة الأفعال التفصيلية ونطاق كل دور، خصوصًا تعديل الحضور والنتائج.
- سياسة الاحتفاظ بالبيانات والملفات والسجلات، وموافقة الخصوصية.
- مزود الهوية، التخزين، النسخ الاحتياطي، OCR والصوت وTelegram إن لزم.

## ملحق التحقق بعد إنشاء العرض

أُجري جرد أولي في بداية المهمة ثم ظهرت ملفات تطبيق إضافية أثناء التنفيذ؛ هذه البيئة ليست Git ولا يمكن معرفة مصدرها أو ترتيبها عبر commits. بقيت الملفات داخل حزمة التسليم دون تعديل. أُنشئ أيضًا تطبيق عرض مستقل في جذر مساحة العمل (`index.html`, `styles.css`, `app.js`) واختُبر محليًا عبر خادم PHP، بينما بقي تطبيق الحزمة (`digital_trainer_codex_handoff/index.html` و`assets/app.js`) مستقلًا.

- نجح `node --check app.js` و`node --check digital_trainer_codex_handoff/assets/app.js`.
- نجح تشغيل الصفحات الإحدى عشرة في تطبيق الجذر عبر متصفح محلي. فُحصت إضافة منشأة تجريبية، ترشيح المحتوى واعتماده، تعديل حضور مع سبب، بحث المستخدمين، وتغيير إعداد محلي؛ لم تظهر أخطاء Console.
- فُتحت نسخة الحزمة عبر خادم PHP وأظهرت لوحة المؤشرات وصفحاتها. ظهر شريط تمرير أفقي في صفحة الجودة ضمن لقطة بعرض نافذة ٨٥٥ بكسل؛ يلزم حسم العرض المستهدف وفحص مظهر هذه النسخة على أجهزة الهاتف.
- هذه فحوص دخان يدوية وليست اختبارات آلية أو فحوص أمن. لا يوجد backend أو حفظ دائم في أي من النسختين.
- النسخة التي يجري تشغيلها من جذر مساحة العمل موثقة بأوامر الجذر `README.md`. الحزمة لها README مستقل؛ يفضل توحيد النسخة المعتمدة بعد مراجعة التغييرات غير المتعقبة وغياب Git.
