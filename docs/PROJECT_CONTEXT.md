# سياق المشروع — المدرب الرقمي

- النطاق التجريبي: الكلية التقنية بالأفلاج، والتوسع التدريجي في منشآت منطقة الرياض.
- اللغة: العربية، واتجاه الواجهة RTL.
- الهدف الحالي: Demo قوي للإدارة والمتدرب، مع قاعة واحدة متصلة فعليًا بـTutori لتوليد شرح حي. بقية بيانات الإدارة والمتابعة تجريبية؛ ثم تجهيز التطبيق الفعلي بناءً على تدقيق المستودع.
- الأدوار: نائب المحافظ للتدريب، مشرف الكليات التقنية، مدير إدارة المنطقة، عميد المنشأة، إدارة الجودة التدريبية، رئيس القسم، المدرب، المتدرب.

## قواعد أساسية
- لا تفترض أن وظيفة موجودة بالإنتاج لمجرد ظهورها في Demo أو HTML.
- استخدم بيانات وهمية فقط في العرض.
- لا تخلط صلاحية عرض التقرير بصلاحية تعديل البيانات.
- لا تسمح بالوصول عبر حدود المنشأة أو القسم أو الشعبة.
- لا تعتبر فتح الدرس وقت تدريب مكتمل تلقائيًا.
- لا تضف خدمات مدفوعة أو مفاتيح API أو تكاملات غير مؤكدة دون موافقة.
- لا تحذف أو تستبدل ملفات قبل فحص Git وحالة العمل.
- وثّق الافتراضات والفجوات والقرارات.

## صفحات Demo الأدمن
لوحة المؤشرات، الكليات والمنشآت، الأقسام، المستخدمون، الأدوار والصلاحيات، المقررات والشعب، المحتوى والاعتماد، الحضور والتقدم، التقارير، الجودة وسجل التدقيق، الإعدادات.

## اتجاه التصميم
حكومي مؤسسي راقٍ، فاتح وأنيق، كحلي/أبيض/أزرق فاتح، RTL حقيقي، خط عربي واضح، Responsive، بيانات تجريبية متسقة. الأزرار والبحث والفلاتر والنوافذ يجب أن تعمل فعليًا.

## مراجع
راجع وثيقة التسليم الفني ووثيقة الهيكلة والصلاحيات وأي HTML أو تصدير Base44 أو CSV للكليات إذا كانت موجودة بالمستودع. إذا لم تكن موجودة، اذكر ذلك واطلب إضافتها إلى docs/؛ لا تدّعِ قراءتها.
