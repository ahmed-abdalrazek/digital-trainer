# قيود الـDemo

- كل السجلات والأرقام والأسماء وهمية ومضمنة في JavaScript.
- لا يوجد حفظ دائم: التغييرات ورسائل النجاح تمثل جلسة العرض فقط.
- لا يوجد تسجيل دخول أو صلاحيات حقيقية؛ إخفاء/عرض العناصر لا يحمي البيانات. بوابة الإدارة لا تحفظ سجلاتها، لكن مثال درس الشبكات في Tutori يحفظ حالة المراجعة والنسخة المنشورة في SQLite محلية.
- قاعة المتدرب تحتوي محاضرة حية واحدة فقط لمقرر الشبكات 101، مدمجة من تطبيق Tutori على `127.0.0.1:7860`. يلزم تشغيل التطبيق المحلي وتوفير مفتاح OpenAI API مع رصيد. توليد الشرح والصوت يستخدم API مدفوعًا حسب الاستعمال؛ لا تُدخل بيانات شخصية أو سرية في الأسئلة.
- مثال الشبكات 101 في Tutori ثابت ومضمّن، وليس توليدًا من ملفات مرفوعة. يراجع المدرب أجزاءه بالتتابع، ويعاين الرسم على محرّك الطالب نفسه، ثم ينشر نسخة محفوظة. المثال بلا صوت محفوظ، ولا يوجد تسجيل دخول أو تفويض مدرب خادمي.
- تشغيل الطالب للنسخة المنشورة لا يستدعي مولّد الدروس؛ أسئلة المتابعة تستدعي OpenAI API عند توفر المفتاح. لا يوجد حفظ لتقدم الطالب أو مزامنة مع بوابة العرض؛ بيانات المقررات والنتائج والحضور خارج القاعة تظل وهمية.
- زر البدء يفتح Tutori في نافذة مستقلة على الجهاز نفسه؛ الخادم مضبوط افتراضيًا على loopback، لذلك مشاركة بوابة الهاتف لا تجعل خدمة Tutori متاحة تلقائيًا على الهاتف.
- مبدّل الأدوار يعرض واجهات توضيحية فقط ولا يمثل تسجيل دخول أو تفويضًا فعليًا.
- مساحة الجودة تعرض بيانات مجمعة وهمية؛ الملاحظات وانتقالاتها وسجل التدقيق مؤقتة في الذاكرة. لا تتصل بالجهات المسؤولة ولا تغيّر نتائج أو حضورًا أو محتوى.
- خط Tajawal يجري تحميله من Google Fonts؛ يلزم اتصال إنترنت لظهوره، مع خطوط بديلة محلية عند انقطاعه.
- الصوت غير متوفر في نسخة الدرس المثال المحفوظة. الردود التفاعلية قد تستخدم صوت Tutori عبر OpenAI API؛ التشغيل التلقائي يعتمد على إذن المتصفح ومستوى الصوت بالجهاز.
- تصدير CSV يولد صفًا تجريبيًا محليًا فقط. لا يوجد تصدير Excel أو PDF.
- رفع مواد المحاضرة والتكاملات غير موجودة؛ زر النشر متاح فقط لنسخة المثال المحلية في Tutori.
- مؤشرات الحضور والتقدم وتغطية العجز توضيحية وليست أساسًا لاتخاذ قرار أو تقرير رسمي.
- لا يجب إدخال بيانات أشخاص حقيقية في هذا الـDemo.
- للوصول عبر الهاتف: شغّل `start-phone-demo.ps1` على شبكة محلية موثوقة. الخادم الثابت بلا مصادقة؛ لا يُعرّض للإنترنت ولا يستخدم على شبكة عامة.

قبل الإنتاج: نفّذ المصادقة، التفويض الخادمي بحسب المنطقة/المنشأة/القسم/الشعبة، اختبارات العزل والأمن، التخزين والنسخ والاستعادة، وسجل التدقيق، ثم اختبارات القبول المحددة في PRD.
