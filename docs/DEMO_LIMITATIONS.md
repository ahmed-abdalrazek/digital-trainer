# قيود الـDemo

- كل السجلات والأرقام والأسماء وهمية ومضمنة في JavaScript.
- لا يوجد حفظ دائم: التغييرات ورسائل النجاح تمثل جلسة العرض فقط.
- لا يوجد تسجيل دخول أو قاعدة بيانات أو API أو صلاحيات حقيقية؛ إخفاء/عرض العناصر لا يحمي البيانات.
- مبدّل الأدوار يعرض واجهات توضيحية فقط ولا يمثل تسجيل دخول أو تفويضًا فعليًا.
- مساحة الجودة تعرض بيانات مجمعة وهمية؛ الملاحظات وانتقالاتها وسجل التدقيق مؤقتة في الذاكرة. لا تتصل بالجهات المسؤولة ولا تغيّر نتائج أو حضورًا أو محتوى.
- خط Tajawal يجري تحميله من Google Fonts؛ يلزم اتصال إنترنت لظهوره، مع خطوط بديلة محلية عند انقطاعه.
- الصوت العربي يعتمد على أصوات تحويل النص إلى كلام المتاحة في نظام الهاتف والمتصفح؛ قد يلزم تنزيل/تفعيل صوت عربي من إعدادات الجهاز.
- تصدير CSV يولد صفًا تجريبيًا محليًا فقط. لا يوجد تصدير Excel أو PDF.
- أزرار الرفع والنشر والتكاملات غير موجودة عمدًا؛ لا يجوز استنتاج أنها متاحة.
- مؤشرات الحضور والتقدم وتغطية العجز توضيحية وليست أساسًا لاتخاذ قرار أو تقرير رسمي.
- لا يجب إدخال بيانات أشخاص حقيقية في هذا الـDemo.
- للوصول عبر الهاتف: شغّل `start-phone-demo.ps1` على شبكة محلية موثوقة. الخادم الثابت بلا مصادقة؛ لا يُعرّض للإنترنت ولا يستخدم على شبكة عامة.

قبل الإنتاج: نفّذ المصادقة، التفويض الخادمي بحسب المنطقة/المنشأة/القسم/الشعبة، اختبارات العزل والأمن، التخزين والنسخ والاستعادة، وسجل التدقيق، ثم اختبارات القبول المحددة في PRD.
