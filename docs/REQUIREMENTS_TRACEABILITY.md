# تتبع المتطلبات

الحالة تصف هذا التسليم فقط؛ ظهور وظيفة في الـDemo لا يعني تنفيذها في منتج حقيقي.

| ID | المتطلب | الحالة | موضع التنفيذ/الدليل | الاختبار | الفجوة |
|---|---|---|---|---|---|
| FR-01 | دخول موثق وحسابات ونطاق | غير منفذ | واجهة مستخدمين تجريبية في `assets/app.js` | لا توجد اختبارات مرفقة | هوية، جلسات، RBAC/ABAC خادمي |
| FR-02 | منشآت/أقسام واستيراد CSV | جزئي — عرض فقط | صفحات المنشآت والأقسام | يدوي مطلوب | لا CRUD دائم أو CSV ومعاينة/كشف تكرار |
| FR-03 | مستخدمون ومتدربون واستيراد | جزئي — عرض فقط | صفحة المستخدمين | يدوي مطلوب | لا حفظ أو مراجعة أو استيراد |
| FR-04 | مقررات وشعب وتسجيلات | جزئي — عرض فقط | صفحة المقررات والشعب | يدوي مطلوب | لا نموذج بيانات أو تكليف فعلي |
| FR-05 | رفع ومراجعة المحتوى | جزئي — واجهة | صفحة المحتوى | يدوي مطلوب | لا رفع/فحص/تخزين/مسار اعتماد |
| FR-06 | درس تفاعلي وحفظ تقدم | غير منفذ | لا يوجد | لا توجد اختبارات | واجهة المتدرب والدروس والتقدم |
| FR-07 | جلسات وحضور وتأخير وأثر تعديل | جزئي — بيانات عرض | صفحة الحضور | يدوي مطلوب | لا احتساب أو سجل خادمي |
| FR-08 | إقرار خطة الفصل | جزئي — مؤشر فقط | KPI الحضور | لا توجد اختبارات | منطق المرة الأولى والتوقيت |
| FR-09 | اختبارات وأوزان ونتائج | غير منفذ | لا يوجد | لا توجد اختبارات | جميع منطق التقييم والتدقيق |
| FR-10 | تقارير وصادرات مقيدة | جزئي — CSV محلي | صفحة التقارير | يدوي: زر التصدير | لا XLSX/PDF أو بيانات/صلاحية فعلية |
| FR-11 | جودة وتدقيق | جزئي — واجهة تجريبية موسعة | `assets/quality-workspace.js`: مراجعة المحتوى، نتائج مجمعة، استبيانات، مقارنة كليات، ملاحظات وسجل | فحوص JavaScript؛ يلزم اختبار متصفح | سجل موثوق وصلاحيات خادمية/ملاحظات دائمة وإثباتات إجراءات |
| FR-12 | الإشعارات والتكاملات | غير منفذ | إعدادات توضيحية | لا توجد اختبارات | لا مزود أو قرار ترخيص/تكلفة |
| NFR | RTL/استجابة/هوية مؤسسية | جزئي | `index.html`, `assets/styles.css` | فحص يدوي مطلوب | يلزم تدقيق وصول ومتصفحات |
| NFR | أمن/خصوصية/نسخ واستعادة | غير منفذ | لا يوجد | لا توجد اختبارات | مطلوب قبل الإنتاج |
